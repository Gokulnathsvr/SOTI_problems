# SOTI Coding Problems & Solutions

## Overview
Welcome to the **SOTI_problems** repository! This project is a dedicated collection of algorithmic solutions to coding challenges frequently asked during the **SOTI hiring assessments and hackathons**. 

This repository serves as an archive of optimized, production-ready code designed to crack the SOTI interview process, focusing heavily on logical problem-solving, time-complexity optimization, and clean code architecture.

## 🧠 Core Problem Categories
SOTI's online assessments typically feature a mix of easy, medium, and hard algorithmic questions. This repository includes optimized solutions for patterns commonly seen in their rounds:
* **Array Manipulations:** Amplification scaling, prefix sums, and subarray optimization.
* **String & Binary Decoding:** Scrambled binary messages, lexicographical sorting, and bit manipulation.
* **Dynamic Programming & Geometry:** Rectangle stacking, maximizing heights/areas, and 2D grid navigation.
* **Search & Optimization:** Greedy algorithms and binary search on answer spaces.
